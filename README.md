## 📋 Sobre o Projeto

O **BAIXADOR-X** é uma ferramenta desktop desenvolvida em Python que permite baixar vídeos do Twitter/X diretamente no formato MP4, otimizado para compatibilidade com WhatsApp e outras plataformas de compartilhamento.

### ✨ Funcionalidades

- 🖥️ Interface gráfica moderna e intuitiva
- ⬇️ Download de vídeos do Twitter/X
- 🎥 Formato MP4 compatível com WhatsApp
- 📁 Seleção de pasta de destino
- 🎨 Ícone personalizado
- 🚀 Execução simples via duplo clique

## 🚀 Como Usar

### Pré-requisitos

- Python 3.x instalado
- yt-dlp
- FFmpeg (recomendado para melhor conversão)

### Instalação

```bash
# Clone o repositório
git clone https://github.com/renatoapdl/BAIXADOR-X.git

# Acesse a pasta
cd BAIXADOR-X

# Instale as dependências
pip install -r requirements.txt
```

### Execução

**Opção 1 (Recomendado):** Execute `Baixador-X.vbs`

**Opção 2:** Execute `Baixador-x.bat`

**Opção 3:** Execute diretamente o Python
```bash
python baixar_twitter.py
```

### Passo a Passo

1. 📋 Cole o link do vídeo do Twitter/X
2. 📁 Selecione a pasta de destino
3. 🎬 Clique em "BAIXAR VÍDEO"
4. ✅ Aguarde o download e confira na pasta selecionada
