# Baixador-X

Downloader de vídeos do Twitter/X em formato MP4 compatível com WhatsApp.

## Funcionalidades

- Interface gráfica moderna (tema escuro)
- Download de vídeos do Twitter/X
- Formato MP4 compatível com WhatsApp
- Seleção de pasta de destino
- Ícone personalizado

## Como Usar

1. Execute `Baixador-X.vbs` (recomendado) ou `Baixador-x.bat`
2. Cole o link do vídeo do Twitter/X
3. Clique em "BAIXAR VÍDEO"
4. O vídeo será salvo na pasta selecionado

## Requisitos

- Python 3.x
- yt-dlp
- FFmpeg (recomendado para melhor conversão)

## Instalação

```bash
pip install -r requirements.txt
```

## Atalho na Área de Trabalho

Para criar um atalho:
1. Clique com botão direito em `Baixador-X.vbs`
2. Selecione "Enviar para" → "Área de trabalho (criar atalho)"
